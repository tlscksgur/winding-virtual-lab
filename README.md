# 권취 가상 실험실

3D 권취 재생, 원본/작업본 제어 코드 비교, 스윙·복귀 설정 실험 도구입니다.

## 새 PC에서 실행

Python 3.10 이상을 설치한 뒤:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe launch.py
```

주소: http://127.0.0.1:18765/

이 저장소는 실행 가능한 Python 제어 소스만 포함한 배포용 복사본입니다.
`original/manifest.json`은 이 저장소에 포함된 기준 소스의 해시이며 원본 ZIP 전체의 검증 목록이 아닙니다.
원래 전체 원본·작업본·실행 기록은 기존 PC에 보존했습니다. 체크포인트 암호는 제거하고
`WINDING_CHECKPOINT_PASSWORD` 환경변수로 대체했습니다.
영상 AI 기능에는 별도의 승인된 Saige 실행 환경·체크포인트가 필요합니다.
3D 및 상태 전이 실험은 영상 AI 없이 사용합니다. 실제 설비 보정이 된 디지털 트윈은 아닙니다.
모델 가중치·사내 영상·vendor 바이너리·로그·결과·백업은 포함하지 않습니다.

## 기존 PC 작업 기록


기본 화면을 3D 실험실로 변경했습니다. `Start-WindingLab.cmd`를 더블클릭하거나 `http://127.0.0.1:18765/`를 엽니다.

치수·rpm·이동 속도·지연 입력 → **조건 적용하고 실험** → 3D 재생 → **코드 수정**에서 복사본 저장 → 동일 조건 재실험 순서로 사용합니다. 원본·수정본은 같은 조건으로 비교합니다.

복사한 Python의 상태 전이·점수·이동 요청이 가상 기계를 움직이고, 움직인 결과가 다시 판단 코드의 입력이 됩니다. 영상 AI는 가상 센서로 대체하므로 현재 PC에서도 실행할 수 있습니다. 실제 치수와 기계 응답이 보정된 현장 디지털 트윈은 아닙니다.

상세 사용법, 치수 계산식, 실행 코드 범위와 가정은 [SIMULATION_GUIDE.md](SIMULATION_GUIDE.md)를 참고하세요. 검사: `.venv\Scripts\python.exe -m unittest discover -s . -p "test_*.py" -v`.

## 이전 영상 검사 도구 안내

아래 내용은 `/replay`에서 여는 이전 영상 검사 화면에 대한 설명입니다. 3D 시뮬레이션에는 위 사용법을 적용합니다.

`Start-WindingLab.cmd`를 더블클릭하면 `http://127.0.0.1:18765`가 열립니다.

이 프로그램은 별도로 복사한 세이지 엔진을 로컬 파일에 실행하는 테스트 도구입니다. 운영 VIMS, 운영 DB, PLC Agent는 실행하지 않습니다. 결과의 이동 요청은 파일에만 기록합니다. 서버는 이 PC의 루프백 주소에만 바인딩합니다. 엔진 자식 프로세스에는 외부 연결·프로세스 실행 차단과 실행 폴더 밖 파일 쓰기 차단을 적용합니다.

## 바로 사용하기

현재 이 PC에서는 Windows 애플리케이션 제어 정책이 세이지 추론 바이너리를 차단합니다. 환경 확인 중 `DLL load failed while importing metadata: 애플리케이션 제어 정책에서 이 파일을 차단했습니다`가 발생했습니다. 보안 정책을 변경하거나 우회하지 않았습니다. 실제 AI 분할·전체 권취 판단 성공은 확인하지 못했으며, 이 두 모드는 차단 이유를 표시합니다. 추론 라이브러리와 체크포인트는 모두 로컬에 확보되어 있습니다.

1. **첨부한 현장 사진 사용 → 테스트 실행**으로 사진·영상 프레임을 확인합니다. 이 모드는 AI 없이 동작합니다.
2. **상태 전이 검사 · 합성 입력**을 선택하고 **원본과 수정본 비교**를 체크한 뒤 실행합니다.
3. **수정용 소스**에서 상태 전이 코드 또는 임계값을 편집하고 **수정본에 저장**합니다.
4. 동일 검사로 원본·수정본의 상태 차이를 비교합니다.
5. 이전 결과는 **이전 실행**에서 다시 열 수 있습니다.

실제 AI 분할·권취 판단은 사내 절차에 따라 라이브러리가 정상 실행되는 상태가 된 후 `probe_environment.py`로 확인해야 합니다. 이 프로그램은 보안 예외를 추가하는 기능을 포함하지 않습니다.

전체 권취 판단에는 같은 시간에 찍은 정면·측면 영상이 모두 필요합니다. 두 영상의 시작점과 FPS를 맞추세요. 측면을 정면 영상으로 대체하지 않습니다. 시퀀스 중간부터 시작하면 엔진 초기화·방향 확정에 필요한 문맥이 부족할 수 있습니다. 첫 비교는 1초 간격, 20초 구간으로 시작하고, 현장 호출 주기에 맞춰 동일 조건으로 비교하세요. CPU를 사용하므로 첫 모델 로딩은 시간이 걸릴 수 있습니다.

**상태 전이 검사**는 합성 점수·각도 입력으로 복사한 `shift_state.py`의 실제 상태 클래스와 타이머를 실행하는 단위 검사입니다. 영상 모델이나 드럼 물리 동작의 결과로 해석하지 않습니다. 코드 일부 변경이 이 검사에 영향을 주지 않을 수 있으며, `shifting.py`의 점수·이동 요청 생성 전체를 검증하지는 않습니다.

## 파일 구분

| 위치 | 역할 |
|---|---|
| `original/source-main.zip` | GitLab에서 내려받은 원본 ZIP |
| `original/source/` | 원본 소스 보관본. 편집 대상 아님 |
| `original/manifest.json` | 원본 파일별 SHA256, 커밋 기록 |
| `working/SaigeWindingMonitoring/` | 사용자가 코드를 바꿀 작업 복사본 |
| `backups/` | 화면에서 저장하기 직전의 작업 파일 |
| `outputs/<실행ID>/<baseline 또는 working>/source/` | 실행에 사용한 소스 스냅샷 |
| `outputs/.../results.jsonl` | 프레임별 상태·점수·가상 이동 요청 |
| `outputs/.../frames/` | 입력과 검출 영역 이미지 |
| `outputs/.../summary.json` | 실행 요약 |
| `outputs/.../console.log` | 엔진 오류 진단 로그 |
| `.runtime/vendor/python/` | 세이지가 제공한 별도 실행 환경 |
| `.venv/` | 테스트 화면·상태 단위 검사용 전용 Python |

원본과 수정본은 실행 시작 시 각자 스냅샷을 만들고 동일한 입력·설정으로 순차 실행합니다. 체크포인트는 각자의 원본/작업 폴더에서 읽습니다. 테스트 화면의 **원본 무결성 확인**은 배포 기준 소스 파일을 SHA256으로 비교합니다. 실행 전후에도 같은 검사를 합니다. GitLab에 커밋·푸시하거나 원격 파일을 변경하는 기능은 없습니다.
